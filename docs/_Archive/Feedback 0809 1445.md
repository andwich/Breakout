## Immediate fix

Replace this line in `play_powerup()`:

```gdscript

```

with either of these safe forms:

```gdscript
var freq: float = notes[note_idx]
```

or, preferably, make the note array typed:

```gdscript
var notes: Array[float] = [400.0, 600.0, 800.0]
var freq: float = notes[note_idx]
```

The second option is more robust because it keeps the entire signal-generation path explicitly typed.[1]

## Corrected function

```gdscript
func play_powerup() -> void:
	var num_samples := int(SAMPLE_RATE * 0.2)
	var data := PackedByteArray()
	data.resize(num_samples * 2)

	var notes: Array[float] = [400.0, 600.0, 800.0]
	var note_duration := 0.2 / notes.size()

	for i in range(num_samples):
		var t := float(i) / SAMPLE_RATE
		var note_idx := mini(notes.size() - 1, int(t / note_duration))
		var freq: float = notes[note_idx]
		var local_t := t - note_idx * note_duration
		var envelope := maxf(0.0, 1.0 - local_t / note_duration)
		var sample := sin(2.0 * PI * freq * t) * 0.3 * envelope
		var val := int(clampf(sample * 32767.0, -32767.0, 32767.0))
		_pack_sample(data, i, val)

	var wav := AudioStreamWAV.new()
	wav.data = data
	wav.format = AudioStreamWAV.FORMAT_16_BITS
	wav.mix_rate = SAMPLE_RATE
	wav.stereo = false
	_play_stream(wav, -6.0)
```

Use your project’s existing naming (`SAMPLE_RATE` vs. `SAMPLERATE`, `_pack_sample` vs. `_pack_sample_data`, etc.) if it differs—the key repair is the typed `notes` declaration and/or explicit `float` on `freq`.[1]

## Why it happens

In Godot 4, `:=` requires the right-hand side to have a determinable static type. A literal such as `[400.0, 600.0, 800.0]` is treated as a generic `Array` unless you declare it as `Array[float]`; indexing it therefore yields a `Variant`, which cannot be used to infer `freq`’s type.[1]

## Audio reliability

`_play_stream()` creates a new `AudioStreamPlayer` for every effect and frees it after completion. That is fine for normal gameplay, and the brick-hit limiter already reduces rapid-fire allocation, but lasers, multiball, and dense destruction can still create frequent transient nodes.[1]

Prefer a small reusable player pool:

- Preallocate 8–16 `AudioStreamPlayer` children in `_ready()`.
- Reuse any non-playing player for normal effects.
- Drop or steal the oldest low-priority sound if all players are busy.
- Keep the existing 28 ms brick-hit rate limiter.

That avoids scene-tree churn and makes audio behavior predictable under heavy gameplay. Your current project documentation already identifies feedback-rate limiting as an intentional design choice, so pooling is consistent with that design.[1]

Also make Master-bus lookup defensive:

func _master_bus_index() -> int:

Use the resulting index only when it is non-negative. This protects startup if the default audio bus layout is altered.[1]

## Save-data safety

`SaveData` works for a simple high score, but it should explicitly close file handles and validate parsed JSON before casting it. The existing code writes only `highscore` to `user://breakout_save.json`.[1]

A safer version:

```gdscript
const SAVE_PATH := "user://breakout_save.json"

func get_high_score() -> int:
	if not FileAccess.file_exists(SAVE_PATH):
		return 0

	var file := FileAccess.open(SAVE_PATH, FileAccess.READ)
	if file == null:
		push_warning("Could not open save file.")
		return 0

	var parsed := JSON.parse_string(file.get_as_text())
	file.close()

	if parsed is Dictionary and parsed.has("highscore"):
		return max(0, int(parsed["highscore"]))
	return 0

func save_high_score(score: int) -> void:
	if score <= get_high_score():
		return

	var file := FileAccess.open(SAVE_PATH, FileAccess.WRITE)
	if file == null:
		push_warning("Could not write save file.")
		return

	file.store_string(JSON.stringify({"highscore": score}))
	file.close()
```

This prevents malformed or manually edited save data from producing unwanted values and makes write failures visible in the debugger.[1]

## Signal and node safety

Your direct injection pattern—setting paddle references and using callbacks/signals instead of parent traversal—is a good Godot 4 design.[1]

For resilience during cleanup and scene changes:

- Use `CONNECT_ONE_SHOT` where a signal should fire exactly once.
- Guard callbacks that can run after `queue_free()` with `is_instance_valid()`.
- Disconnect long-lived autoload signals in `_exit_tree()` if the receiver is not itself an autoload.
- Prefer `get_node_or_null()` for scene-node dependencies that may change during iteration.

Example:

```gdscript
if not ball.lost.is_connected(_on_ball_lost):
	ball.lost.connect(_on_ball_lost, CONNECT_ONE_SHOT)
```

This protects against accidental duplicate connections after restarts or rebinding.[1]

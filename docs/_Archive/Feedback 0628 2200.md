### 🟡 New finding — `_setup_laser_manager()` called too often, with a latent bug inside it

`_setup_laser_manager()` does double duty: it rebinds the laser manager *and* recomputes wall bounds from `$LeftWall` / `$RightWall`:

```gdscript
func _setup_laser_manager() -> void:
	if laser_manager == null:
		return
	laser_manager.set_paddle(paddle)
	laser_manager.set_can_fire_check(...)
	var left_shape  := $LeftWall/CollisionShape2D.shape  as RectangleShape2D
	var right_shape := $RightWall/CollisionShape2D.shape as RectangleShape2D
	paddle.wall_left_x  = ...
	paddle.wall_right_x = ...
	_slow_timer = Timer.new()       # <-- creates a NEW Timer
	...
	_combo_timer = Timer.new()      # <-- creates a NEW Timer
	...
	_combo_label = Label.new()      # <-- creates a NEW Label
	...
```

This function is called from `_run_setup()`, `_start_new_run()`, `_load_level()`, `_spawn_ball()`, and the Laser power-up branch — i.e. **every single time a ball spawns**, including every life lost and every level load. Each call re-creates `_slow_timer`, `_combo_timer`, and `_combo_label` from scratch via `Timer.new()` / `Label.new()` and `add_child()`s them — **without freeing the previous ones**. The old timer/label nodes are simply leaked as orphaned children of `main` and `hud`.

Concretely: every time `_spawn_ball()` runs (every round, every life), you get a new orphaned `Timer` for slow-balls, a new orphaned `Timer` for combo, and a new orphaned combo `Label` sitting invisibly in the HUD tree. Over a long Endless run this is a slow, unbounded node leak — and worse, only the *last-created* `_combo_timer`/`_combo_label` is reachable through the member variable, so any signal connections made to the old ones become orphaned dead listeners.

This was masked previously because the old bug (missing `_run_setup()` on Endless entry) meant this path basically never got hit repeatedly in long sessions. Now that `_run_setup()`/`_setup_laser_manager()` runs reliably, the leak is exposed continuously.

**Fix — split one-time setup from per-spawn rebinding.** Move timer/label creation into `_run_setup()` only (called once), and trim `_setup_laser_manager()` down to just paddle binding + wall bounds (the parts that are cheap and idempotent):

```gdscript
func _run_setup() -> void:
	_base_position = position

	_bind_laser_manager()
	laser_manager.brick_scored.connect(_on_brick_hit)
	laser_manager.laser_fired.connect(AudioManager.play_laser_fire)
	paddle.set_sticky_release_callback(func(): return _is_phase_playing())

	_update_wall_bounds()

	_slow_timer = Timer.new()
	_slow_timer.one_shot = true
	_slow_timer.timeout.connect(_restore_ball_speeds)
	add_child(_slow_timer)

	_combo_timer = Timer.new()
	_combo_timer.one_shot = true
	_combo_timer.wait_time = 0.6
	_combo_timer.timeout.connect(_reset_combo)
	add_child(_combo_timer)

	_combo_label = Label.new()
	# ... (unchanged setup) ...
	hud.add_child(_combo_label)

	_flash_overlay = ColorRect.new()
	# ... (unchanged) ...
	hud.add_child(_flash_overlay)

	_slow_overlay = ColorRect.new()
	# ... (unchanged) ...
	hud.add_child(_slow_overlay)

	_spawn_background_particles()

func _bind_laser_manager() -> void:
	if laser_manager == null:
		return
	laser_manager.set_paddle(paddle)
	laser_manager.set_can_fire_check(func(): return phase == GameState.Phase.PLAYING)

func _update_wall_bounds() -> void:
	var left_shape  := $LeftWall/CollisionShape2D.shape  as RectangleShape2D
	var right_shape := $RightWall/CollisionShape2D.shape as RectangleShape2D
	paddle.wall_left_x  = $LeftWall.position.x  + left_shape.size.x  / 2.0
	paddle.wall_right_x = $RightWall.position.x - right_shape.size.x / 2.0
```

Then replace every other call site:
- `_start_new_run()`: `laser_manager.deactivate(); _bind_laser_manager()`
- `_load_level()`: `laser_manager.deactivate(); _bind_laser_manager()`
- `_spawn_ball()`: `_bind_laser_manager()` (paddle ref doesn't change between spawns in practice, but this keeps it cheap/safe if it ever does)
- Laser power-up branch: `_bind_laser_manager(); laser_manager.activate(duration)`

This keeps the "always re-bind paddle + can-fire check before any laser-dependent action" guarantee from the original design intent, but removes the per-spawn node churn.

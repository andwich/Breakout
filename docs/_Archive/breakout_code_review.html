1

No wall collision bodies

Balls pass through top and side edges — collision_mask=5 but no wall StaticBody2D in main.tscn. Top/side exits silently queue_free the ball.

main.tscn · ball.gd _on_screen_exited

Critical
2

Pause/unpause permanently broken

Guard phase == PAUSED → return blocks unpausing. Once paused, Escape does nothing. PAUSED phase is also re-used for level transitions, creating the conflict.

main.gd _toggle_pause()

Critical
3

Paddle sprite doesn't resize on big-paddle

sprite.size.x = target_width has no effect on offset-based Controls. Collision shape grows but visual stays the same width. Fix: set sprite.offset_left / offset_right.

paddle.gd apply_big_paddle() · _reset_paddle_width()

Critical
4

PAUSED phase conflated with level transition

complete_level() sets phase = PAUSED but doesn't pause the tree. This shares state with player pause, making both harder to reason about. Add a _transitioning flag instead.

main.gd complete_level()

Significant

Play mechanisms

5

Y-clamping diluted by subsequent normalization

_clamp_min_speed() sets velocity.y ≥ 50, but the next line velocity = velocity.normalized() * speed re-scales it down below 50 again on shallow angles.

ball.gd _physics_process · _clamp_min_speed()

Critical
6

signf(0.0) = 0 — perfectly horizontal ball locks

If velocity.y is exactly 0, signf(0.0) * 50 = 0. The ball stays horizontal forever. Use 50.0 if velocity.y >= 0 else -50.0.

ball.gd _clamp_min_speed()

Critical
7

Multiball spawns 1 clone, readme says 2

The loop iterates active balls once, spawning one clone each. With one ball you get two total, not three. Add an inner loop or adjust the readme.

main.gd _on_powerup_collected MULTIBALL

Significant
8

Laser scoring uses get_parent() — fragile coupling

Contradicts the project's own design rule (agents.md: "Avoid get_parent() for core gameplay"). Breaks if LaserManager ever moves in the tree. Emit brick_scored(int) instead.

laser_manager.gd _fire_laser()

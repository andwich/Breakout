### Critical — `main.gd` will fail to parse (game cannot launch)

`_start_new_run()` has a whitespace bug: lines 142–156 are indented with a **leading space followed by a tab** (`" \t"`), while every other line in the file uses tabs only.

```
	if _combo_tween and _combo_tween.is_valid():
		_combo_tween.kill()
 	if _combo_label:              # ← starts with SPACE + TAB
 		_combo_label.visible = false
 	if _shake_tween and _shake_tween.is_valid():
 		_shake_tween.kill()
 	if _flash_tween and _flash_tween.is_valid():
 		_flash_tween.kill()
 	if _slow_tween and _slow_tween.is_valid():
 		_slow_tween.kill()
 	if _flash_overlay:
 		_flash_overlay.color.a = 0.0
 	if _slow_overlay:
 		_slow_overlay.color.a = 0.0
 	_shake_intensity = 0.0
 	position = _base_position
 	laser_manager.deactivate()
	_bind_laser_manager()              # ← back to tab-only
```

Godot 4's GDScript parser rejects mixed tab/space indentation within the same block (`"Used tab characters within the same indentation block as spaces"`), which is exactly the class of bug flagged in `agents.md` rule #21 (typed arrays) and the headless-validation workflow (rule #28) is designed to catch. This is a **hard parse failure** — the project won't even reach the title screen. It's isolated to this one block (confirmed via full-repo scan; no other `.gd` file has mixed indentation).

**Fix**: retype lines 142–156 so every line begins with a single tab, matching the rest of the function:

```gdscript
	if _combo_tween and _combo_tween.is_valid():
		_combo_tween.kill()
	if _combo_label:
		_combo_label.visible = false
	if _shake_tween and _shake_tween.is_valid():
		_shake_tween.kill()
	if _flash_tween and _flash_tween.is_valid():
		_flash_tween.kill()
	if _slow_tween and _slow_tween.is_valid():
		_slow_tween.kill()
	if _flash_overlay:
		_flash_overlay.color.a = 0.0
	if _slow_overlay:
		_slow_overlay.color.a = 0.0
	_shake_intensity = 0.0
	position = _base_position
	laser_manager.deactivate()
	_bind_laser_manager()
```

Simplest concrete fix in your editor: select lines 142–156 and re-indent (or delete-and-retype the leading whitespace) so no line starts with a space. This is exactly the failure mode the "Headless Validation Gate" step in `agents.md` (rule #28) exists to catch — worth re-running `godot --headless --path . --editor --quit` after this fix and before the next session, since a parse error like this would otherwise block everything else from being testable.

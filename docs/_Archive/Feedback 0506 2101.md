**Play mechanisms**

The most damaging active bug is issue #1. The current clamp sequence in the bounce branch:

```gdscript
velocity = velocity.bounce(normal)
velocity = velocity.normalized() * speed
if absf(velocity.y) < 50.0:
    velocity.y = 50.0 if velocity.y >= 0.0 else -50.0
    velocity = velocity.normalized() * speed  # ← undoes the x clamp below
if absf(velocity.x) < 50.0:
    velocity.x = 50.0 if velocity.x >= 0.0 else -50.0
    velocity = velocity.normalized() * speed  # ← undoes the y clamp above
```

Each renormalize collapses the component that was just clamped. The fix is one normalization, then both clamps without renormalizing:

```gdscript
velocity = velocity.bounce(normal)
velocity = velocity.normalized() * speed
if absf(velocity.y) < 50.0:
    velocity.y = 50.0 if velocity.y >= 0.0 else -50.0
if absf(velocity.x) < 50.0:
    velocity.x = 50.0 if velocity.x >= 0.0 else -50.0
# Speed changes slightly but trajectory is correct — acceptable tradeoff
```
